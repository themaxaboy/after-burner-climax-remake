# AFTER BURNER CLIMAX — Web Remake (fan project)

A browser remake of SEGA's 2006 arcade jet shooter *After Burner Climax* (and its 2013 Android port),
built with three.js (WebGL2) and a heavy post-processing pipeline, with a Top Gun: Maverick-inspired mood.

> Fan project. No SEGA or Top Gun assets, music, logos or voices are used — every model, sound and
> texture is generated procedurally or comes from CC0 sources (Poly Haven).

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit tests (vitest)
npm run build    # production build in dist/
```
